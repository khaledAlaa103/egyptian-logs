# WELLLOG PRO — User guide / دليل المستخدم

## English
1. **Project & well** — Projects → New; Wells → New (unique well ID, depth, type).
2. **Import** — Import: CSV/Excel (map columns, check units and nulls), manual entry, or an image/PDF
   of a log (Digitize: calibrate depth and value axes, trace the curve, review quality, export).
3. **View** — Viewer: wheel = zoom, drag = pan, click = cursor, drag header dividers = resize tracks.
4. **Formations** — add tops/bottoms, lithology, water-bearing state.
5. **Interpret** — choose Rt route, Rw (direct, SP, or water sample), Vsh, porosity and Sw models and
   enter *your* parameters. Missing inputs give "unavailable", never a guess.
6. **Results** — Excel-like table by interval; edit (marked as override), filter, screen with your
   cut-offs, snapshot, export XLSX/CSV.
7. **Water** — enter samples; calibrate EC→TDS from your own data; salinity class.
8. **Reports** — pick sections, language (AR/EN), export PDF/XLSX/CSV.
9. **Backup** — Settings → Backup regularly (clearing browser data deletes the local database).

Shortcuts: Alt+1…9 navigate sections; arrows/+/−/Home in the viewer; Ctrl+Z/Y in results.
Status codes: **M** measured · **C** corrected · **K** calculated · **E** estimated · **U** unavailable.

## العربية
1. **المشروع والبئر** — المشاريع ← جديد، الآبار ← جديد (رقم بئر فريد، العمق، النوع).
2. **الاستيراد** — CSV/Excel (ربط الأعمدة وفحص الوحدات والقيم الفارغة)، أو إدخال يدوي، أو صورة/PDF للّوج
   (الرقمنة: معايرة محوري العمق والقيمة، تتبّع المنحنى، مراجعة الجودة، ثم التصدير).
3. **العرض** — العجلة = تكبير، السحب = تحريك، النقر = المؤشر، سحب فواصل الرأس = تغيير عرض المسار.
4. **التكوينات** — أضف الأعماق والليثولوجيا وحالة الحمل المائي.
5. **التفسير** — اختر طريقة Rt وRw (مباشر أو من SP أو من عينة مياه) ونماذج Vsh والمسامية وSw وأدخل
   **معاملاتك أنت**. المدخلات الناقصة تعطي «غير متاح» ولا تُخمَّن.
6. **النتائج** — جدول شبيه بإكسل لكل فترة؛ تعديل (يُعلَّم كتجاوز)، تصفية، فرز بحدودك، لقطات، تصدير.
7. **المياه** — أدخل العينات؛ عايِر EC→TDS من بياناتك؛ تصنيف الملوحة.
8. **التقارير** — اختر الأقسام واللغة وصدّر PDF/XLSX/CSV.
9. **النسخ الاحتياطي** — من الإعدادات بانتظام (مسح بيانات المتصفح يحذف قاعدة البيانات المحلية).

الاختصارات: Alt+1…9 للتنقل بين الأقسام. الرموز: **M** مقاس · **C** مصحَّح · **K** محسوب · **E** مقدَّر · **U** غير متاح.
