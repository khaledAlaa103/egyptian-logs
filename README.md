# WELLLOG PRO

Offline-first well-log interpretation and groundwater analysis (Arabic RTL / English LTR).
Runs as a web app, installable Android PWA, and Windows desktop app (Electron).

```bash
npm install --legacy-peer-deps
npm run dev          # development
npm test             # unit + UI tests
npm run build        # production build (dist/)
npm run electron:pack  # Windows installer in release/
```
